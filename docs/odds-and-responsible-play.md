# 赔率、独立性与理性购彩

> 本章借鉴 GitHub 上 `dungnotnull/lottery-statistics-responsible-play-advisor-agent-skill` 的框架：以组合数学、独立事件与行为经济学解释彩票，**明确不生成任何有预测力的号码**。本项目所有选号功能的定位是统计演示，不是投注建议。

## 1. 精确头奖概率

| 彩种 | 样本空间 | 组合数 | 单注中头奖概率 |
| --- | --- | --- | --- |
| 双色球 SSQ | 33 选 6（无放回、无序）× 蓝球 16 选 1 | `C(33,6) = 1,107,568`，`× 16` | **1 / 17,721,088** |
| 大乐透 DLT | 35 选 5 × 12 选 2 | `C(35,5) = 324,632`，`C(12,2) = 66` | **1 / 21,425,712** |
| 七星彩 QXC | 前 6 位各 0~9，第 7 位 0~14 | `10⁶ × 15` | **1 / 15,000,000** |

这些都是**组合计数**，与历史开奖数据无关，也不因「冷热号」「遗漏值」改变。买 `m` 注不同号码，头奖概率是 `m / 样本空间`，仅线性增长——把注数翻倍，概率仍然极小。

顺带纠正一个常见误解：「形态约束」（和值、奇偶比、AC 值、分区）看似能「缩小范围」，但它同时缩小了样本空间和候选注数，条件概率 `P(中奖 | 满足形态)` 与 unconditional 概率相同。这正是本项目保留结构塑形却不声称提升中奖率的原因。

## 2. 每期独立

摇奖设备没有记忆。上一期开出什么、某个号码遗漏了多久、连出几期奇数，都不会改变下一期任一号码的出现概率。本项目的全历史检验（χ²、游程、累计和、序列模式、样本外 walk-forward）反复验证的就是这一点：

```
P(第 t+1 期号码 = x | 前 t 期全部历史) = P(第 t+1 期号码 = x)
```

「该回补了」「冷号该热了」属于**赌徒谬误**；「连开几期说明有趋势」属于**热手谬误**。二者在独立事件上都不成立。

## 3. 期望值

单注期望收益：

```
EV = Σ_i P(第 i 等奖) × 奖金_i − 单注成本
```

彩票的奖金池来自销售额的一部分，因此对所有参与者整体必有 `EV < 0`。具体数值随奖池、奖级、派奖规则变化，本项目不编造；可以确定的是：**任何选号策略都不改变 `P(第 i 等奖)`，因此也不改变 EV**。

这与 [方法论](methodology.md) 的恒等式 `E[命中数] = k²/N` 是同一件事的两个层面：前者针对奖金，后者针对命中个数。

## 4. 常见认知偏差

| 偏差 | 典型说法 | 为什么不对 |
| --- | --- | --- |
| 赌徒谬误 | 「这个号 30 期没出，快了」 | 每期独立，遗漏不累积「欠债」 |
| 热手谬误 | 「最近连出大号，跟着买」 | 独立序列没有动量 |
| 控制错觉 | 「自己选的比机选更有把握」 | 自选与机选概率完全相同 |
| 近失效应 | 「差一个号，说明方法有效，再试一次」 | 差一个号在概率上并不更接近中奖 |
| 幸存者偏差 | 「有人用这个方法中了」 | 中奖者被看见，海量未中奖者不被报道 |
| 模式幻觉 | 「走势图里有规律」 | 随机序列中必然会出现局部聚类与形状 |

行为经济学里，Langer 的控制错觉、Tversky & Kahneman 的代表性启发式、Wagenaar 对赌徒认知的研究都解释了这些直觉为何顽固。本项目用可复现的统计实验把这些直觉逐条证伪，而不是用另一套「玄学」去替代。

## 5. 理性提示

- 把购彩当作**娱乐消费**，事先设定可承受的预算，不追加、不追损、不借贷。
- 不把任何软件、公式、「内部数据」当作提高中奖率的手段——包括本项目。
- 若出现持续加大投入、隐瞒支出、影响工作与生活等迹象，请及时寻求专业帮助。
- 未成年人不得购彩。

## 6. 本项目的边界

- `data` 策略是 Fisher-Yates 严格均匀抽样 + 结构软约束，**期望命中与完全随机选号相同**；
- `smart` 策略是已证伪的传统加权路线，保留仅作对照；
- 本仓库不提供任何「预测中奖号码」能力，也不接受以中奖率为目标的贡献（见 [CONTRIBUTING](../CONTRIBUTING.md)）。

本章仅作概率教育与风险提示，不构成投注、法律或财务建议。
